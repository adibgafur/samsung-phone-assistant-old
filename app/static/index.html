System Architecture & Workflow

Overview of the four core pillars built for the Samsung Phone Query and Review System.

Step 1

Web Scraper & Database

Scrapes 10-15 popular Samsung smartphones from GSMArena (BeautifulSoup + requests) with polite delays. Normalizes battery, display size, RAM, and prices into relational tables (PostgreSQL / SQLite).

Step 2

Conversational RAG Chatbot

Retrieves exact specifications and precomputed catalogue rankings based on entity extraction and TF-IDF search. Groq LLM (Llama 3.3 70B) generates grounded answers with zero hallucinations.

Step 3

Multi-Agent Pipeline

Divided into two autonomous roles: SpecRetrievalAgent queries the database and computes relative market rank, while ReviewWriterAgent crafts a comprehensive, structured product review.

Step 4

FastAPI Service & Web UI

Clean RESTful endpoints (/chat, /review, /phones, /api/verify-key) paired with an interactive frontend that supports dynamic in-browser Groq API key configuration.
